# issue_tracker

# Note

As TheParasiteProject is personal project, support for devices that we don't maintain is very limited.

Also, before you open issue ticket, please take a valid logs (logcat for Android System crashes etc.) and upload it.

Otherwise, issue will be closed as we couldn't do anything much.

# Description

Issue tracker to get bug report, PR, etc for TheParasiteProject.

If you added PRs to other repo, but if I didn't noticed, you could report that here too!

All issues and PRs: [TheParasiteProject Issues & PRs](https://github.com/pulls?q=user%3ATheParasiteProject+user%3ATheParasiteProject-Devices)
